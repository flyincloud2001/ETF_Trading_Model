This project selects 'good' ETFs by filtering them with criteria including low volatility, minimum daily trading volume, listing age, and IBKR tradeability. For each selected ETF, historical daily returns are analyzed to identify the return range where next-day open rebounds are most frequent and significant, which serves as the ranking standard. Then, by looking up yesterday's ETF return, the system decides which ETFs are worth a bet for today's rebound.
